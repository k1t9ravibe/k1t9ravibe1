# Мониторинг стоимости аренды

Корпоративная информационная система АО «Казахтелеком» для анализа стоимости аренды помещений при закупках способом из одного источника.

**Процесс:** создание заявки → расчёт цены за 1 м² → сравнение с базой цен → выявление превышения → уведомление → запрос обоснования (при необходимости) → сохранение результатов.

**Дополнительно:** накопление базы цен → анализ рыночных предложений → формирование региональных ценовых ориентиров → выгрузка аналитической справки.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
```

Требуется Node.js 20+.

## Хранение данных

| Режим | Когда | Особенности |
|---|---|---|
| Локальная база браузера | по умолчанию | Данные сохраняются между перезагрузками, но видны только в этом браузере на этом компьютере |
| Supabase (PostgreSQL) | заданы `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` | Общая база для всех пользователей |

Подключение Supabase:

1. Создайте проект на supabase.com.
2. Выполните [supabase/schema.sql](supabase/schema.sql) в SQL Editor.
3. Скопируйте `.env.example` в `.env` и укажите URL и anon-ключ проекта.
4. Перезапустите `npm run dev`. Пустая база заполнится демонстрационными данными.

> В схеме включены открытые политики доступа для пилота. Перед промышленной эксплуатацией замените их политиками для аутентифицированных пользователей.

## Методика ценового ориентира

- Цена за 1 м² = ежемесячная стоимость аренды / площадь.
- Ориентир — **медиана** фактических ставок по сопоставимым объектам за последние 12 месяцев (период настраивается).
- Сопоставимость сужается по уровням: НП + тип + диапазон площади → НП + тип → регион + тип. Используется первый уровень, на котором набирается минимальное количество объектов (по умолчанию 3). Если ни на одном уровне данных не хватает, выводится «Недостаточно данных для формирования ценового ориентира».
- Рыночные предложения показываются справочно и в ориентир не включаются.
- Превышение не блокирует заявку — ориентир носит рекомендательный характер.
- Согласованная заявка автоматически добавляется в базу цен как завершённая закупка.

## Разделы

- **Главная** — панель мониторинга: фильтры, карточки показателей, таблица заявок с подсветкой и боковой панелью.
- **Заявки** — создание и редактирование с автоматическим расчётом, запрос обоснования, ответ заказчика с вложениями, история.
- **База цен** — записи, группировка по региону, НП, типу и площади; средняя, медиана, мин., макс., количество; добавление, редактирование, импорт и выгрузка Excel.
- **Рыночный мониторинг** — предложения, средняя и медианная рыночная цена, ручной ввод и импорт Excel. Интеграция с Krisha.kz запланирована (только через официальный доступ).
- **Аналитика** — схематичная карта регионов, цены по регионам, динамика по месяцам, сравнение типов помещений, доля заявок с превышением.
- **Справки** — официальная справка с параметрами, датой и источником; Excel, PDF, печать.
- **Настройки** — параметры методики, пользователь, сброс и удаление демо-данных.

## Демонстрационные данные

25 заявок, около 1 300 записей базы цен и около 340 рыночных предложений по 20 регионам. Все они помечены как «демо». Их можно восстановить или удалить в «Настройках».

React 19 + TypeScript, Vite, Tailwind CSS 4, Recharts, ExcelJS, jsPDF + html2canvas-pro, Supabase JS, React Router.
